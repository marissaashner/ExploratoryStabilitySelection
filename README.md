# Exploratory Stability Selection

## Marissa C. Ashner

Software supplement for the manuscript *An Exploratory Stability Selection (ESS) Framework for Robust Predictor Discovery: An Application to Physical Resilience in Aging Populations*

In this repository, you will find the following programs:
- `02_ClinicalPredictorsTrajectoriesAnalysis_20260428.Rmd`: This script runs the analysis for the clinical predictor set with the pain interference trajectory outcome for the ESS Illustration.
- `03_BiomarkerTrajectoriesAnalysis_20260428.Rmd`: This script runs the analysis for the biomarker predictor sets with the pain interference trajectory outcome for the ESS Illustration.
- `04_ClinicalAndBiomarkerTrajectoriesAnalysis_20260428.Rmd`: This script runs the analysis for the combined predictor set with the pain interference trajectory outcome for the ESS Illustration.
- `05_RegressionsAndOutputs_20260428.Rmd`: This script runs all regressions for ESS Illustration and uses the stability scores to create tables and heat maps.

**Note:** The data used for this illustration is unavailable for public use. Without the data, this script will not run on its own. *It is shared for the purposes of understanding and utilizing the methods involved with the ESS pipeline.*
